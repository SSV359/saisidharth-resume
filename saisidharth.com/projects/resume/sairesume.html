PaddleHubs

Pickleball tournament and player-management platform, officially partnered with DUPR.

PaddleHubs is a pickleball tournament and player-management platform I founded and developed to make organizing, competing in, and tracking pickleball events easier and more engaging. It gives players a centralized place to view leaderboards, tournaments, match history, schedules, player profiles, and weekly results.

The platform supports both individual and team-based competition, with team lineups, win tracking, rankings, and performance statistics. It aims to create a more competitive and connected pickleball community by giving players a structured way to track their progress and take part in organized events.

PaddleHubs is built on a cloud architecture using AWS services including Amazon S3, CloudFront, API Gateway, Lambda, DynamoDB, and Cognito. Beyond the software itself, it has been used to organize local pickleball events and competitions, including team-based and round-robin tournaments, and is officially recognized and partnered with DUPR (Dynamic Universal Pickleball Rating).

Architecture & key details
  • Built on AWS: Amazon S3, CloudFront, API Gateway, Lambda, DynamoDB, and Cognito.
  • One place for leaderboards, tournaments, match history, schedules, player profiles, and weekly results.
  • Supports individual and team competition: team lineups, win tracking, rankings, and performance statistics.
  • Officially recognized and partnered with DUPR (Dynamic Universal Pickleball Rating).
  • Used to run local pickleball events, including team-based and round-robin tournaments.
  • Long-term vision: expanded rankings, tournament management, player analytics, and eventually a mobile app.

CyberSmart ATL

Student-led digital safety and cybersecurity awareness initiative for young students.

Summer Camp 2025 · Day by Day
1 / 5

  1. Day 1 · Online Privacy & Personal InformationWe kicked off the week by learning what personal information really is, why it matters, and how to protect it from strangers and unsafe websites using simple, smart online habits.

  2. Day 2 · Making PasswordsCampers discovered how to build strong, secure passwords and explored how hackers try to break them using brute-force attacks, weak guesses, and reused logins.

  3. Day 3 · Phishing, Scams & Fake MessagesWe learned how to recognize fake messages, suspicious links, and emotional tricks that scammers use to steal personal info — and how to avoid falling for them.

  4. Day 4 · MalwareStudents explored the world of malware, including viruses and spyware, and how clicking the wrong link or downloading from untrusted sources can harm devices and steal data.

  5. Day 5 · Recap SessionWe wrapped up the week by reviewing all our lessons through games and real-life scenarios that showed just how much everyone had learned — and how ready they are to stay safe online.

CyberSmart ATL is a student-led digital safety and cybersecurity awareness initiative I founded to help young students understand how to stay safe in an increasingly digital world.

Through interactive workshops and educational programs, CyberSmart ATL teaches elementary and middle-school students essential topics including online privacy, strong passwords, phishing detection, malware defense, scam awareness, and responsible digital behavior. It has hosted free educational camps combining short lessons, interactive activities, and gamified labs to make cybersecurity engaging, reaching 60+ students.

Program details
  • Workshops cover online privacy, strong passwords, phishing detection, malware defense, scam awareness, and responsible digital behavior.
  • Free educational camps combine short lessons, interactive activities, and gamified labs.
  • Built for elementary and middle-school students, with 60+ students reached.
Cloud & Web Developer·Live

Website Architecture

This resume website, hosted on AWS and deployed automatically from GitHub.

I designed and deployed a fully functional personal resume website using AWS and GitHub services. The site is hosted on an Amazon S3 bucket configured for static website hosting and serves HTML, CSS, and image assets.

I integrated AWS CloudFront as a content delivery network (CDN) to enable HTTPS, improve load times, and provide global caching. DNS routing is handled by AWS Route 53, which maps the custom subdomain (resume.saisidharth.com) to the CloudFront distribution.

Code for the website is version-controlled in a GitHub repository, and I implemented a CI/CD pipeline using GitHub Actions that automatically deploys updates to the S3 bucket on every push to the main branch. I also secured this website using a ZeroSSL certificate.

This architecture demonstrates my ability to work with cloud infrastructure, automate deployments securely, and deliver scalable, production-grade web solutions.

Architecture & key details
  • Amazon S3 bucket configured for static website hosting.
  • AWS CloudFront CDN for HTTPS, load times, and global caching.
  • AWS Route 53 DNS mapping resume.saisidharth.com to the CloudFront distribution.
  • GitHub Actions CI/CD pipeline that deploys on every push to the main branch.
  • ZeroSSL certificate securing the site.
